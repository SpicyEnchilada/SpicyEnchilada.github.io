How to Join Blastonia

Follow these quick steps to download the overhaul and get playing

01

Join Discord

Join our official Discord server to get current announcements, server password (if set), and live support.

02

Download Mod

Click the Download Overhaul button above or grab the zip/Mod Launcher link directly from our Discord channel.

03

Install Files

Extract the overhaul files into your 7 Days to Die/Mods folder (or use 7D2D Mod Launcher).

04

Connect & Play

Launch 7D2D (EAC Disabled), search for Blastonia in the server browser or connect via IP.
